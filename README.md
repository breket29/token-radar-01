Token Radar ranks every pre-token protocol in DefiLlama's sealed snapshot by implied launch value — TVL times its category's median market-cap-per-TVL among traded names, adjusted for 7-day growth, age with no token, and chain breadth — with a concrete farm plan for each one and a static dashboard to browse the board, filter it, and open any protocol's detail view.

## Run it

```sh
node main.ts --input snapshot.json --output out
```
